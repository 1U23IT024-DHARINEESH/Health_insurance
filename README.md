# Health Insurance Prediction

## Project Overview

Health Insurance Prediction is a Machine Learning project that predicts individual health insurance charges based on different personal and demographic factors.

The project uses data analysis, visualization, preprocessing, and Machine Learning techniques to understand the factors that influence insurance costs and predict the expected insurance charges.

## Problem Statement

Health insurance charges vary among individuals based on factors such as age, BMI, smoking habits, number of children, gender, and region. Manually estimating insurance costs can be difficult.

This project develops a data-driven system that analyzes these factors and predicts health insurance charges using Machine Learning techniques.

## Objectives

* Analyze health insurance customer data.
* Identify important factors affecting insurance charges.
* Clean and preprocess the dataset.
* Perform Exploratory Data Analysis (EDA).
* Visualize relationships between different variables.
* Build a Machine Learning model to predict insurance charges.
* Evaluate the performance of the prediction model.

## Dataset

The dataset contains **1,338 records and 7 attributes**.

 Attribute  Description                      
 --------- -------------------------------- 
 age        Age of the individual            
 sex       Gender of the individual       
 bmi        Body Mass Index                  
children  Number of children or dependents
smoker    Smoking status                   
 region     Residential region               
 charges    Medical insurance cost           

The `charges` column is the **target variable** used for prediction.

The project analyzes the relationship between insurance charges and factors such as:

* Age
* BMI
* Smoking status
* Gender
* Number of children
* Region

Different graphs and statistical visualizations are used to identify patterns and relationships in the dataset.

## Machine Learning

The processed dataset is used to train a Machine Learning model for predicting the `charges` value.

The model is evaluated using appropriate performance metrics to understand its prediction performance.

## Expected Outcome

The system provides a data-driven method for estimating individual health insurance charges based on customer characteristics.

It also helps identify the major factors that influence health insurance costs.
